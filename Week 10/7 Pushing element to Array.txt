We want to push Group by age:29 and push hobbies: [ 'Cooking', 'Skiing' ]


1. First Start :

>> db.students.aggregate([
    {
        $group:{_id:{age:"$age"},allHobbies:{$push:"$hobbies"}}
    }
])

==> 

[
  { _id: { age: 30 }, allHobbies: [ [ 'Eating', 'Data Analytics' ] ] },
  {
    _id: { age: 29 },
    allHobbies: [ [ 'Sports', 'Cooking' ], [ 'Cooking', 'Skiing' ] ]
  }
]

យើងឃើញថាវាជាប់ Array allHobbies: [ [ 'Sports', 'Cooking' ], [ 'Cooking', 'Skiing' ] ]
ចឹងវាពិបាក Extra data from [[]] 

==> We can use $unwind: "$hobbies"

3. we use unwind and addToSet ( we use addToSet instead of push because in addToSet No duplicate element ) 

>> db.students.aggregate([
    {
        $unwind: "$hobbies"
    },
    {
        $group:{_id:{age:"$age"},allHobbies:{$addToSet:"$hobbies"}}
    }
])

==>

[
  {
    _id: { age: 29 },
    allHobbies: [ 'Sports', 'Cooking', 'Cooking', 'Skiing' ]
  },
  { _id: { age: 30 }, allHobbies: [ 'Eating', 'Data Analytics' ] }

]
