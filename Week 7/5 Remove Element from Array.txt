** Remove last element or first element from Array **  Pop 

-1 : Frist Element 
1  : Last Elment 


Example :

hobbies: [
      { title: 'Cars', fre: 2, goodFre: 'Yes' },
      { title: 'Cooking', fre: 5, goodFre: 'Yes', isNewField: true },
      { title: 'Dring', fre: 5 },
      { title: 'Shopping', fre: 1 },
      { title: 'Song', fre: 7 },
      { title: 'Swimming', fre: 1 }
    ],

+ Remove Last element : { title: 'Swimming', fre: 1 }


>> db.users.updateOne({name:"Dara"},{$pop:{hobbies:1}})
