>> newDB> db.users.find({hobbies:{$size:3}})

==>

  {
    _id: ObjectId('67f89017dd3d70fac28bf20c'),

3. Find all the users that hobbies : song and book 

>>db.users.find({hobbies:{$all:["song","book"]}})

==> 

[
  {
    _id: ObjectId('67f8939fdd3d70fac28bf20d'),
    name: 'Many',
    hobbies: [ 'book', 'song' ]
  },
  {
    _id: ObjectId('67f893d1dd3d70fac28bf20e'),
    name: 'Dina',
    hobbies: [ 'song', 'book' ]
  }
]

** ចង់រក hobbies = sport and fre > 3

>> db.users.find({hobbies:{$elemMatch:{title:"sport",fre:{$gt:3}}}})


==>
