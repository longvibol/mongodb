---------------------------------------------------------------------------------------

1. find element or field that have age: true 

>> db.users.find({age:{$exists: true}})

==>

[
  {
    _id: ObjectId('67f73a8120cb0108fb8bf203'),
    name: 'Dara',
    hobbies: [ { titile: 'fishing', fre: 5 }, { titile: 'cooking', fre: 3 } ],
    phone: '099887766',
    age: 30
  }
]

2. find field that does not have field age: "false"

>> db.users.find({age:{$exists: false}})

==> 

[
  {
    _id: ObjectId('67f73a8120cb0108fb8bf202'),
    name: 'Piseth',
    hobbies: [ { title: 'sport', fre: 5 }, { titile: 'cooking', fre: 5 } ],
    phone: 2734381
  }
]

------------------------------------------------------------------------------

3. Combine condition : Want to find field document that have field "age" and this age >=30

>> db.users.find({age:{$exists: true, $gte:30}})

==> 
[
  {
    _id: ObjectId('67f73a8120cb0108fb8bf203'),
    name: 'Dara',
    hobbies: [ { titile: 'fishing', fre: 5 }, { titile: 'cooking', fre: 3 } ],
    phone: '099887766',
    age: 30
  }
]
