Or, and , not, nor :syntax :db.collectioName.find({$--[{$--},{$--}]})

1. Using "$or" 

find runtime less than 30 or greater than 60 

>> db.movies.find({runtime:{$lt:30}}) 

==> 2 document 

>> db.movies.find({runtime:{$gt:60}})

==> 2 document 

So we can combine with this two condition 

>> db.movies.find({$or:[{runtime:{$lt:30}},{runtime:{$gt:60}}]}) 

==> 4 documents 

=================================================================================

2. $nor 

>> db.movies.find({$nor:[{runtime:{$lt:30}},{runtime:{$gt:60}}]}).count()

==> 236 

3. find move Drama and time more than 30 min 

>> db.movies.find({$and:[{runtime:{$gt:30}},{genres:["Drama"]}]}).count()
==> 8

* Short Cut with AND * Logical Qurey 

We no need to put $and 

>> db.movies.find({runtime:{$gt:30},genres:["Drama"]})

==> 8 document 

Why we create $and logic if it have short cut !

Think this case below : 

>>  db.movies.find({genres:"Drama",genres:"Horror"}).count()

==> 23 document 

វាចាប់យក តម្លៃ genres:"Horror" អោយតាមាន Horror movie វាយកមកហើយ វា Over Right លើ genres:"Drama"​ 
ចឹងសម្រាប់ លទ្ធផល សុទ្ធតែមាន Horror 

But if we use $AND វាយកតម្លៃពីរនឹង ផ្គួបចូលគ្នា

>>db.movies.find({$and:[{genres:"Drama"},{genres:"Horror"}]}).count()

==> 17 document
