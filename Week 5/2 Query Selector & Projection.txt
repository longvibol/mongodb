1. Count 

>> db.movies.find().count()

2. specific field 

>> db.movies.find({runtime:60})

3. $eq : Matches values that are equal to a specified value

>> db.movies.find({runtime:{$eq:60}}).count()

==> 170

4. $ne : Matches all values that are not equal to a specified value.

>> db.movies.find({runtime:{$ne:60}})


5. $gt :  Matches values that are greater than a specified value.

>> db.movies.find({runtime:{$gt:60}}).count()

==> 2

------------------------------ Search Embedded two field or more than field ----------------

* Embedded :  rating: { average: 7.8 },

1. want movie that have rating more than 7 

>> db.movies.find({"rating.average":7}) 

or 

>> db.movies.find({"rating.average":{$eq:7}}).count()

---------------------------------- Find In and Not In 

1. រកតែចំនួនណាដែលមាននៅក្នុង Arrays [] 

>> db.movies.find({runtime:{$in:[30]}})

វាចេះតែ Movie ណាដែលមាន រយៈពេល 30 គត់

2. find movie that have runtime 30 និង 42

>> db.movies.find({runtime:{$in:[30,42]}})

វាមិនមែនជា ចន្លោះទេ វាបង្ហាញតែ លេខ​ 30 and 42 only 

3. Not in $nin

>> newDB> db.movies.find({runtime:{$nin:[30,42]}}) 

- វាចាប់យកតែក្រៅពី លេខ 30 and 42
