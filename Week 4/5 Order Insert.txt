ចឹងយើងឃើញថាវាចូលបាន អាខាងមុខវា​ ព្រោះវា Order Insert : it is default 

----------------------------------------------------------------------------------------

Solution : យើងជាអ្នកកំណត់ បើចង់អោយវា add ចូលយើងត្រូវដាក់ ordered: false ជា default it is "true"

>> db.hobbies.deleteOne({_id:"movie"})

>>  db.hobbies.insertMany([{_id:"movie",title:"Movie"},{_id:"cooking",title:"Cookding"},{_id:"song",title:"Song"},{ordered:false}])

>> 

db.hobbies.insertMany([],{}) - {} : it called configuration 

>> studentDB> db.hobbies.find()
[
  { _id: 'sport', title: 'Sport' },
  { _id: 'cooking', title: 'Cookding' },
  { _id: 'car', title: 'car' },
  { _id: 'movie', title: 'Movie' }
]

ចឹងយើងឃើញថាវា Insert ចូលទោះបីវាមាន duplicate key ក៏បាន
