3. Find Near by location and have Max distance from our currently locate 

We test by the google map from Petal KH to Aeon Sen Sok 289m 

>> db.places.find({location:{$near:{$geometry:{type:"Point",coordinates:[104.8855484, 11.6016388]},$maxDistance:240}}})

==>[
  {
    _id: ObjectId('68084f8f19fd6367f08bf202'),
    name: 'Aeon Mall Sen Sok',
    location: { type: 'Point', coordinates: [ 104.8834623, 11.6021669 ] }
  }
]

- Key word : $maxDistance:240

- In case it does not have near by location it will not show anything ! 

Explanation:

- $geometry: Defines the reference point for the query.
- $minDistance: Ensures that only documents at least 500 meters away are included.
- $maxDistance: (Optional) Limits the results to documents within 5000 meters.

This query will return all stores that are between 500 meters and 5000 meters from the specified point. Let me know if you'd like further clarification or additional examples!
